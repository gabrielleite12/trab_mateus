> conceitos_da_aula.md

🩺 Supervisor de Software

Monitora o liveness probe (heartbeat). Se uma thread ou processo travar (CPU a 100%) e parar de responder, ele aplica um restart policy para liberar os recursos roubados.

Watchdog (Cão de Guarda)

Temporizador de hardware (ou virtual) que conta regressivamente. Se o SO travar e não resetar o timer, ele estoura e força o reset/reboot da máquina (VM ou Host).

Escalonador

Maestro do SO. Decide quem usa o núcleo do processador e quando. (Thread = Tarefa; no kernel Linux a unidade agendada se chama task).

Quantum

O tempo máximo (fatia) que uma thread pode rodar sem interrupção no núcleo.

Heartbeat

Sinal contínuo que comprova que o processo não está travado.

Kernel vs Hipervisor

Kernel é o núcleo do SO (gerencia hardware); Hipervisor é quem engana o hardware para criar VMs completas. (Tipo 1 = Roda direto no hardware ex. ESXi; Tipo 2 = Roda sobre um SO ex. VirtualBox).

Interrupções de Hardware

Sinal que faz o processador parar o que está fazendo (ex: IRQ 1 = teclado / IRQ 12 = mouse no PC clássico legacy).

MTTR e Docker Desktop

MTTR = Mean Time To Recovery (Tempo de detecção+reset+boot). Docker no Windows/Mac roda sobre uma VM leve (WSL2/HyperKit).

OverlayFS vs VM

Containers reusam imagem/page cache via OverlayFS (leve). VMs duplicam tudo.

Trits e Quântica

Setun (URSS, 1958) usou trits (1 trit ≈ 1,585 bits). "Ternário antes do quântico" é aposta, não consenso. Quântico é coprocessador (como GPU), não substituto total do clássico.

Hierarquia de Memória (Latências/Custo)

L1 ~1ns / RAM ~70-100ns / SSD ~100µs / HD ~5-10ms. Preços: SRAM (cache) caríssima, DRAM (RAM) ~US$/GB, NAND (SSD) centavos.
